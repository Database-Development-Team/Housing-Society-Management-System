
# Housing Society Management System

A web-based application for managing housing society operations.

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: Oracle Database 11g XE
- Database Tool: Oracle SQL Developer

## Main Modules

- Owner and Property Management
- Tenant, Lease and Resident Management
- Visitor and Vehicle Management
- Maintenance Billing
- Complaint Management
- Facility Booking
